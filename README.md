# Florería Duhau · Maqueta

Maqueta visual e interactiva del sitio de Florería Duhau, versión 3.

Publicada en https://bue-studio.github.io/duhau-maqueta/ mediante GitHub Pages.

El archivo `index.html` incluye sus imágenes, estilos y scripts. Es un prototipo de presentación: los formularios, el carrito y las opciones de entrega muestran interacciones de ejemplo y no procesan pedidos ni pagos reales.

Para actualizar la maqueta, reemplazar `index.html` y subir el cambio a la rama `main`.
